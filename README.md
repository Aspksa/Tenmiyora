# Tenmiyora

Версия **0.2.0** — запуск на Windows, автоматическая подготовка переносного Python, локальный сервер и начальная страница.

## Запуск

1. Скачайте проект целиком через **Code → Download ZIP** и распакуйте архив.
2. Запустите **Tenmiyora.bat** двойным щелчком.
3. После проверки Python откроется браузер. Консоль свернётся в трей рядом с часами. Если значок скрыт Windows, откройте стрелку скрытых значков.

Нужны Windows 10/11 и Windows PowerShell 5.1. Если рабочий Python **3.10 или новее** уже есть, используется он. Если Python отсутствует или не прошёл проверку, BAT автоматически скачает официальный переносной Python **3.14.10** с `www.python.org`, проверит SHA-256 и подготовит его внутри `.runtime\python`. Сторонние Python-пакеты, Node.js и права администратора не требуются. Установка Python в Windows, изменение PATH и реестра не выполняются.

Для автоматической подготовки нужен интернет только при первой загрузке (архив около 12 МБ). Архитектура сборки выбирается по Windows: x64, x86 или ARM64. Версия, URL и SHA-256 закреплены в `bootstrap/python-runtime.json`; хеши взяты с [официальной страницы выпуска](https://www.python.org/downloads/release/python-31410/). Загрузка выполняется по HTTPS с ограничением времени и одной повторной попыткой. При ошибке сети, несовпадении SHA-256 или неудачном пробном запуске установка прекращается, окно остаётся открытым с объяснением. Для повторной попытки достаточно снова запустить BAT.

Архив распаковывается во временную папку только после проверки SHA-256. Python проверяется до и после переноса в рабочую папку. Если замена существующей локальной среды не удалась, предыдущая папка восстанавливается. Завершённые и неудачные загрузки очищаются; прерванная закрытием консоли подготовка не используется при следующем запуске. Уже подготовленный рабочий Python запускается без загрузки и проверки обновлений в интернете.

Поиск рабочего Python: `.runtime\python\python.exe` → `.venv\Scripts\python.exe` → `py -3` → `python` / `python3` → реестр установленных Python. Каждый кандидат проверяется на версию и необходимые стандартные модули; неподходящие пропускаются. Embedded Python можно распаковать в `.runtime\python` без pip.

Папка проекта может находиться на другом диске или содержать пробелы, кириллицу и `!`. Запуск не зависит от текущей папки командной строки. Папка должна быть доступна для записи, архив необходимо распаковать целиком.

## Управление

Меню значка в трее: **Открыть Tenmiyora**, **Показать консоль**, **Свернуть в трей**, **Открыть журналы**, **Выход**. Двойной щелчок по значку открывает сайт. Повторный запуск BAT открывает уже работающий экземпляр. Для завершения используйте **Выход**. При недоступном трее консоль остаётся видимой.

Параметры одного BAT, отдельные ярлыки не нужны:

```bat
Tenmiyora.bat --console
Tenmiyora.bat --no-browser
Tenmiyora.bat --portable --no-browser
```

`--console` оставляет консоль видимой; `--no-browser` запускает без открытия браузера; `--portable` использует только `.runtime\python`, автоматически подготавливая его при необходимости. Параметры можно сочетать. При ошибке окно показывается и ожидает нажатия клавиши. Журналы каждого запуска и сервера находятся в `.runtime`; токен сеанса в `session.json` нельзя публиковать. Эта папка исключена из Git вместе с локальными средами Python.

## Основа

Сервер использует только `127.0.0.1`, а свободный порт назначается операционной системой. После подготовки Python сеть и интернет для работы не нужны. Файлы проекта через HTTP не раздаются. Управление сервером защищено случайным токеном сеанса, проверками Host и Origin. Закрытие процесса запуска отслеживается сервером для завершения фоновой копии.

`bootstrap/launch.ps1` управляет запуском и треем, `bootstrap/python-runtime.ps1` готовит переносной Python, `bootstrap/probe.py` проверяет Python, `bootstrap/server.py` содержит сервер и начальную страницу. Полноценных модулей, чата, обновлений и базы данных в этой версии ещё нет.

## Проверки

```console
python -m unittest discover -s tests -v
```

GitHub Actions проверяет сервер на Linux и Windows, синтаксис всех PowerShell-скриптов, реальный запуск BAT, автоматическую загрузку Python при отключённом поиске системных интерпретаторов и повторный запуск без манифеста загрузки. Тесты с контролируемыми архивами проверяют сетевой сбой, отклонение неверного SHA-256, сбои пробного запуска и восстановление предыдущей папки.

Перед выпуском на Windows: проверить двойной щелчок по BAT из папки `Тест проекта !`, запуск с другого диска и из другой текущей папки, занятые порты, повторный запуск, показ/скрытие консоли, выход из трея, отсутствие Python и закрытие консоли. Автоматические тесты сервера не заменяют проверку Windows-трея.
