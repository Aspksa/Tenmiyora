Диск Tenmiyora.

Ваши файлы хранятся на компьютере. Поддерживаемые тексты автоматически пополняют Мозг.

Перетащите файлы сюдаили нажмите, чтобы выбрать · до 25 МБ на файл

Файлы и папки

DOCX, XLSX, TXT, Markdown, исходный код и другие текстовые файлы индексируются автоматически. Для PDF требуется установленный pypdf; изображения, архивы и неподдерживаемые форматы сохраняются без извлечения знаний. Файлы не загружаются в Cloud.ru сами по себе; релевантные фрагменты могут передаваться модели при обращении к чату.
